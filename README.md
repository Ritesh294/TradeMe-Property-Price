# TM Property Price

Basic NodeJS App to automatically check the listed price for properties on TM. - Note: This app is somwhat slow as it utilizes puppeteer to search for listings.

### Installation and Use

***Prerequisite:***

Node.js® (https://nodejs.org/en/download/)

Clone or download this repository:

```
git clone https://github.com/Ritesh294/TradeMe-Property-Price.git
```

Install npm packages:

```
npm install
```

Start the app:

```
npm start
```

If your browser does not automatically open after starting the app, go to: http://localhost:3000
